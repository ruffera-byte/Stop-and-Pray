Stop & Pray v2

Upload ALL files in this folder together to the same directory on your web host.

Included:
- index.html
- manifest.json
- stop-pray-icon.png
- apple-touch-icon.png
- favicon-32.png
- icon-192.png
- icon-512.png

What changed:
- Every new tally now records an exact timestamp.
- Optional personalized prayer text is saved with the tally.
- Prayer Log lets you review a selected day's entries.
- Tap a day in the calendar to view that day's log.
- Prayer Rhythm includes hourly, day-part, and 28-day visualizations.
- Existing daily totals remain compatible. Old tallies cannot be assigned historical timestamps, so they appear as older untimestamped tallies.
- ?add=1 Action Button behavior is preserved and now records a timestamp automatically.

Important:
The site still stores all prayer data locally in the browser/device using localStorage.
